# **App Name**: LinkCraft

## Core Features:

- URL Shortening: Accept a long URL and generate a shortened, unique URL.
- Custom Alias: Allow users to specify a custom alias for the shortened URL (if available).
- URL Redirection: Redirect the short URL to the original long URL when accessed.
- User Authentication: Implement signup and login functionality to manage user accounts.
- Link Management: Allow logged-in users to view, edit, and delete their shortened URLs.
- Analytics Tracking: Track the number of clicks on each shortened URL

## Style Guidelines:

- Primary color: A calming, modern blue (#64B5F6) to instill trust.
- Background color: Light gray (#F0F4F7), a desaturated version of the primary, for a clean interface.
- Accent color: A vibrant green (#9CCC65), analogous to the primary, for call-to-action buttons.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a clean, modern, and readable interface.
- Use simple, clear icons from a consistent set (e.g., Material Design Icons) to represent actions and links.
- Maintain a clean, intuitive layout with clear spacing and visual hierarchy for easy navigation.
- Use subtle animations for transitions and feedback, such as a loading animation when shortening URLs.
